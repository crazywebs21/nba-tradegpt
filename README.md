# NBA TradeGPT

NBA trade machine and 7-game simulator.

## Official link

**Play NBA TradeGPT:** https://crazywebs21.github.io/nba-tradegpt/

The site is deployed automatically to GitHub Pages when changes are pushed to `main`.

## Playoffs

A standalone, offline Play-In and playoff bracket simulator is available at [Playoffs](https://crazywebs21.github.io/nba-tradegpt/playoffs.html). It simulates standings and team strengths; it does not use real current standings or player rosters. The existing TradeGPT page remains unchanged.
